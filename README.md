# DriveEase — Car Rental Management System

A modern, responsive academic project built with HTML, CSS and vanilla JavaScript.

## Requirements covered

- Homepage with hero section, company introduction, featured cars and CTA
- Car listing with image, name, price/day, fuel, seats and availability
- Search and filters by model/category/fuel
- Booking form with validation and automatic rental calculation
- Responsive mobile/tablet/desktop design
- Navigation and footer
- Car details / interactive showroom
- LocalStorage booking history
- Demo login UI
- Dark mode
- Animations and modern UI

## Advanced showroom features

The Explore button opens an interactive showroom with:

- Exterior / interior / dashboard views
- Door open/close visual state
- Window open/close visual state
- Sunroof state
- Luxury feature section
- Specifications
- Book this car action

## Run in VS Code

1. Extract the ZIP.
2. Open the extracted `Car-Rental-Management-System` folder in VS Code.
3. Install the **Live Server** extension (recommended).
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Test the site.

You can also double-click `index.html`, but Live Server gives a better development experience.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `car-rental-management-system`.
2. Upload all files and folders from this project.
3. Open repository **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your live `github.io` link.

## Notes

- Car images are loaded from public Unsplash image URLs for demonstration. Replace them with your own appropriately licensed images if your institution requires fully self-owned assets.
- This project uses LocalStorage instead of a server/database, so bookings are saved only in the browser used for testing.
- Login is a demonstration UI, not production authentication.
